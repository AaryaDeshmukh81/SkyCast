# SkyCast — Weather Dashboard

A responsive weather dashboard built with HTML, CSS, and JavaScript that fetches real-time weather data using the Open-Meteo REST API.

## Features

- Search weather by city name.
- Display temperature, humidity, wind speed, and precipitation.
- Show weather conditions and feels-like temperature.
- Handle API errors, invalid cities, and loading states.
- Responsive design for desktop and mobile devices.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API, Async/Await
- Open-Meteo REST API
